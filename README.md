#Mapping with R

A list of general approaches to create Geo Heat Map using R based on Australian Statistical Geography Standard (ASGS) digital boundaries, which are available in either the OGC GeoPackage, or ESRI shapefile formats, which are available to download from the [Australian Bureau of Statistics](https://www.abs.gov.au/statistics/standards/australian-statistical-geography-standard-asgs-edition-3/jul2021-jun2026/access-and-downloads/digital-boundary-files)
